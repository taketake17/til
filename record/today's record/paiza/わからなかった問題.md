# 3/29 問題
```
正整数 n が入力されるので、 n から 1 まで 1 ずつカウントダウンするプログラムを作成してください。

例えば

3
と入力された場合

3
2
1
と出力して下さい。
```
という問題。最初はfor文を使おうとしたが、最初の数字がどうしても引かれてしまうのでどうしたもんかと思った。解答が
```
let n=Number(lines[0]);
    for(let i=n;i>0;i--){
        console.log(i);
        }
```
というもの。理論は簡単でfor文の構造（1ずつ足していく）の逆バージョンにするだけ。
