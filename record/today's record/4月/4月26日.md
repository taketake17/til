　３つの値から比較して大きいものを割り出す問題。最初に書いたコード

```
 if(a>b&&c){
console.log(a)
}else if(b>a&&c){
console.log(b)
}else{
console.log(c)
```
ただこれだと途中から比較されずなので正しくは
```
 let a=Number(lines[0]);
    let b=Number(lines[1]);
    let c=Number(lines[2]);
    
    if(a>=b && a>=c){
        console.log(a);
    }else if(b>=a && b>=c){
        console.log(b);
    }else{
        console.log(c)
    }
```
でした。
