```
{

-forEach の挙動

```
{
    const tests =[70,90,80,85];
    tests.forEach((test,index) =>{
        console.log(`${index}:${test}`);
    })

```
こっちの方がスッキリ書けるので基本こっちで
```
const nums = [3, 2, 8];

nums.forEach((num, i) => {
  console.log(i * 3);
});
```
ややこしかった問題
numには配列の数字が入ってiには上からの順番が入る
そのため、0,1,2といった感じで入っていく

-配列の値を集計してみよう

```
{
    const tests =[70,90,80,85];
    //0で初期化
    let sum = 0;
    tests.forEach((test,index) =>{
        sum +=test;
        console.log(`${index}:${test}`);
    })
    console.log(`Sum:${sum}`);
    console.log(`Average:${sum/tests.length}`);
}
```
まずはlet sum =0;で合計の初期化.
反復処理の中でsum += testとすることで取ってきた要素をsumに足し合わせていく

　}

オブジェクトのキーを指定することでその値を持って来れる

- プロパティを追加、削除してみよう
  ```
  {
    const scores= { math :80 ,english : 90};
    delete scores['english'];
    scores['physics']=70;;
    console.log(scores);
  }
  ```
  定数名＋['新しいキー']＝値;で新しいプロパティを追加できる。　そして
  delete.scores['キー'] でそのプロパティを削除できる

  - Object.entries()
    ```
    {
    const scores= { math :80 ,english : 90};

    const entries=Object.entries(scores);
    console.log(entries);

    entries.forEach((prop) =>{
        console.log(`${prop[0]}:${prop[1]}`);

    });
    }
    ```
    Object.entries()でオブジェクトを配列に変換できる。それをforEachを使うことで取り出せる
    forEachは定数名.forEach(()=>{  })で使える


  
    Object.entries(scores)は、オブジェクトのキーと値のペアを配列の形で返します. この場合、entriesは以下のような2次元配列になります:
```
[
  ['math', 80],
  ['english', 90]
]
```
forEachループで各要素（prop）を反復処理する際、各propは上記の内部配列（例：['math', 80]）を表します.

したがって:

propは配列の最初の要素、つまり教科名（キー）を参照します。

prop[1]は配列の2番目の要素、つまり点数（値）を参照します。

このため、console.log(${prop}:${prop[1]})は教科名と対応する点数を出力できるのです.

より明示的に書くなら、以下のように分割代入を使用することもできます:

```
entries.forEach(([subject, score]) => {
    console.log(`${subject}: ${score}`);
});
```
この方法では、配列の要素を直接変数に代入し、より読みやすいコードになります.
