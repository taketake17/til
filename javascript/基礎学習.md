-配列に要素を追加・削除
```
末尾に要素を追加.push
    .popは末尾から要素を削除
    unshiftは先頭に要素を追加
    shiftは先頭から要素を削除
```
これらメソッドを使えば可能

-配列と反復処理を組み合わせよう

```
{
    const test =[70,90,80,85];
    test.push(2,10,7);

    for(let i =0;i<test.length;i++){
        console.log(test[i]);
    }
    
}
```
for文を使うことで１つずつ要素を取り出せる。数の指定については定数名.lengthで要素の数を指定できるので増えても対処可能

-forEach()の挙動を理解しよう

```
{
    const tests =[70,90,80,85];
    tests.forEach((test,index) => {
        console.log(`${index} :${test}`);

    });
}

```
forEachとアロー関数で反復処理ができる
forとの違いはforだとbreakが使えてループの途中で抜け出せるが、forEachではそれが無理

-forEach の挙動

```
{
    const tests =[70,90,80,85];
    tests.forEach((test,index) =>{
        console.log(`${index}:${test}`);
    })
}
```
こっちの方がスッキリ書けるので基本こっちで
```
const nums = [3, 2, 8];

nums.forEach((num, i) => {
  console.log(i * 3);
});
```
ややこしかった問題
numには配列の数字が入ってiには上からの順番が入る
そのため、0,1,2といった感じで入っていく

-配列の値を集計してみよう

```
{
    const tests =[70,90,80,85];
    //0で初期化
    let sum = 0;
    tests.forEach((test,index) =>{
        sum +=test;
        console.log(`${index}:${test}`);
    })
    console.log(`Sum:${sum}`);
    console.log(`Average:${sum/tests.length}`);
}
```
まずはlet sum =0;で合計の初期化.
反復処理の中でsum += testとすることで取ってきた要素をsumに足し合わせていく
